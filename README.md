## 📌 Sobre o Projeto
Sistema de gerenciamento de estoque e cadastro de produtos desenvolvido para uma loja de velas aromáticas artesanais. O objetivo do sistema é controlar o fluxo de insumos (como potes de vidro, adesivos personalizados) e os produtos finais, garantindo a organização do negócio.

## 🚀 Funcionalidades Entregues (AC1)
A primeira fase do projeto contempla a funcionalidade central do negócio:
- [x] **Arquitetura em 3 Camadas:** Front-end, Back-end e Banco de Dados 100% integrados.
- [x] **Banco de Dados (MySQL):** Criação da tabela `velas` com campos para nome, aroma, descrição sensorial, preço e quantidade.
- [x] **Back-end (Python/Flask):** Rota estruturada para recebimento de requisições POST.
- [x] **Front-end (HTML/CSS):** Interface responsiva desenvolvida com Bootstrap (Dark Theme) para cadastro de novos produtos.

## 🛠️ Como rodar o projeto localmente
1. Certifique-se de ter o serviço do MySQL rodando em sua máquina.
2. Instale as dependências executando no terminal:
   `pip install flask mysql-connector-python`
3. Execute a aplicação Python:
   `python app.py`
4. Acesse pelo navegador através do endereço `http://127.0.0.1:5000`
